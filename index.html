HTML (HyperText Markup Language) é uma linguagem de marcação utilizada para criar e estruturar páginas da internet. Por meio de elementos e tags, o HTML organiza conteúdos como textos, imagens, links, vídeos e tabelas, permitindo que os navegadores exibam essas informações de forma adequada. Ele é uma das principais tecnologias utilizadas no desenvolvimento web e geralmente é combinado com CSS, responsável pelo estilo, e JavaScript, responsável pela interatividade das páginas.
